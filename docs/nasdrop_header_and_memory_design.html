4. 核心 Bug 专项排查与技术方案 需求 5、8 对应
问题项 根因诊断 解决与实施方案
5. 视频播放完锁屏黑屏 播放器到达 STATE_ENDED 后，锁屏导致底层 SurfaceView 销毁。开屏时虽然创建了新 Surface，但 ExoPlayer 处于播毕闲置态，不会向新 Surface 投送画面帧。 在 Lifecycle.Event.ON_RESUME 与 AndroidView 的 update 回调中增加检查：若播放状态为 STATE_ENDED，自动执行 player.seekTo(player.currentPosition) 触发强制解码与首帧重绘，保持画面停留在最后一帧，彻底消除黑屏。
8. 折叠时语音时长不对 远端扫描嗅探到伴生音频时默认赋予 1000L 占位，而折叠微胶囊 UI 优先使用了未纠偏的 entry.audioDurationText（导致始终显示 0:01），忽略了 audioPlayer.durationMs 实际真实时长。 1) 折叠微胶囊取值调整为：优先读取 audioPlayer.durationMs，次选数据库有效时长，剔除 0:01 占位硬编码。
2) 音频在 prepare / 播放时通过真实 MediaPlayer.duration 实时反哺纠正 PhotoMetadataStore，确保微胶囊与列表角标完全一致。
4. 视频全屏与画幅 画幅 FIT/ZOOM/FILL 切换存在黑边缩放冗余，横屏全屏按钮置于顶部容易被视频画面遮挡误触。 彻底移除画幅切换功能；将“全屏/退出全屏”按钮移至底部控制条右侧（倍速药丸旁），直观便捷。
5. 视频播放手势操控全面升级（灵敏、顺滑、零误触） 新增专项 Review

🎮 手势类型与交互响应

  • • 水平左右滑动：屏幕左右无极快进/快退，HUD 实时呈现 ⏩ +15s (01:25 / 04:30)，松手瞬时精确定位；
  • • 垂直左侧滑动：调节屏幕亮度（1%~100% 线性无卡顿渐变，记录手势起点零超调）；
  • • 垂直右侧滑动：调节媒体音量（0%~100% 系统音量精准对齐，记录手势起点零超调）；
  • • 双击操作：左侧 35% 双击快退 10s；右侧 35% 双击快进 10s；中间 30% 双击切换播放/暂停（不触发单击闪烁）；
  • • 长按操作：右侧/中间长按触发 2.0X 极速播放；左侧长按触发 快退回溯；松手立即平滑还原。

🛡️ 防误触与顺滑机制

  • • 20px 启动死区：滑动位移达到 20px 才确认进入手势，消除误碰抖动；
  • • 轴向单向锁定：一旦判定为水平快进或垂直亮度/音量，整个手势过程严格锁定该轴向，斜向滑动绝对不窜动；
  • • 线性基准记忆：开始滑动时锁定初始亮度与音量值，绝对位移映射，杜绝此前累加造成的“一滑到底”数值暴增；
  • • 单双击消抖分流：单击控制栏切换与双击快进快退严格分离，彻底杜绝双击时控制栏疯狂闪烁的问题。
