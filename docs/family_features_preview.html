⚡ 低资源特性与实现架构解析

功能模块 家庭实际场景与价值 技术实现方案 (为什么超低资源) 开发与部署成本
🍼 宝宝/成长月龄轴 长辈和父母最爱的回忆方式，替代冰冷公历日期，按小宝“X岁X月X天”直观回看。 零 NAS 负担。纯前端利用已有照片 EXIF 拍摄时间与预设生日动态换算，端侧本地分组排版。 极低 · 纯客户端
📌 家庭冰箱贴留言板 家人间留便签、备忘提醒、WiFi密码，解决微信消息容易被冲淡、老人容易忘记的痛点。 单文件 WebDAV。NAS 端仅维护一个 2KB 的 family_notes.json，客户端轻量 PUT/GET，秒开秒响应。 极低 · 单 JSON
🎵 声音记忆胶囊 留存老人说方言故事、宝宝牙牙学语。比冷冰冰的照片更有沉浸感动。 同目录下生成轻量 .m4a 音频文件（几十KB），相册检测同名音频即悬浮展示播放波形，不占用转码资源。 低 · 标准音频
🗄️ 重要证照百宝箱 就医、孩子报名、缴燃气费时快速调出医保卡、户口本、维修卡，带指纹安全锁。 约定 _FamilyVault/ 特殊文件夹或标星目录，手机本地离线持久化缩略图 + Android 生物识别 BiometricPrompt。 低 · 目录书签+锁
🧹 手机安全空间瘦身 长辈和家人手机容量常年爆满（64G/128G），不敢乱删照片导致手机卡顿。 端侧比对已上传到 NAS 的完整哈希/时间大小列表，精准筛选已完备备份文件，通过 MediaStore 仅删除手机本地副本。 中低 · 客户端比对
